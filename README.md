# FedA3: Adaptation-Aligned Posterior Aggregation for Personalized Federated Image Recognition under Domain Heterogeneity

![Framework](/Figure/framework.png)

Abstract: *Personalized federated learning (PFL) supports collaborative image recognition in multimedia applications without sharing raw images. However, variations in image style and acquisition conditions introduce domain heterogeneity across clients. Effective personalization requires shared knowledge that supports adaptation to local visual distributions. Clustered approaches pursue this goal by learning shared models for related clients, but two challenges remain: 1) Client association based on geometric similarity does not directly assess adaptation suitability. 2) Posterior-only aggregation overlooks posterior confidence when weighting updates from boundary clients. To address these challenges, we propose FedA\textsuperscript{3}, a personalized federated image recognition framework with Adaptation-Aligned Posterior Aggregation. Specifically, Meta-Compatibility Posterior Inference (MCPI) assesses adaptation suitability for each candidate head through alignment between training and validation gradients. This criterion guides posterior membership inference. Boundary-Aware Meta-Aggregation (BAMA) then uses posterior confidence derived from these memberships to regulate client contributions during meta-aggregation. Extensive experiments on PACS, Office-Home, CIFAR-10, and CIFAR-100 demonstrate the effectiveness of FedA\textsuperscript{3} under domain heterogeneity and label distribution skew.*
